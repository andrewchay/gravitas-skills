# 客户需求蒸馏工作流（速记 → 试点）

把碎片化的客户沟通变成：结构化场景 → 客户原始需求 → 组织本质 → 可一周落地的试点。
核心立场：**Agent 面向客户（client-facing），不是面向内部（internal）。能力不应该被用户看见，解决方案才是。**

## 何时使用

- 拿到客户沟通速记 / 微信记录 / 会议纪要，需要变成结构化分析与行动
- 已有场景清单，但怀疑"只是替人做内部动作"，需要回到客户原始需求
- 要在多个候选场景中选第一个试点（一周级或季度级）
- 要向内部决策者（合伙人 / 基金方 / 管理层）汇报立项并索取决策

## 六个阶段（可裁剪，顺序建议保留）

### 阶段 0：证据盘点

列出全部输入材料，每条信息标注三类：**客户原话 / 档案记录 / 推断**。
纪律：客户提及 ≠ 客户批准；档案数字（如"5 人做对账"）≠ 实测基线；外部对标案例口径未核验前只能作参照。

### 阶段 1：速记翻译 → 场景卡

逐条速记产出场景卡：原文存档｜场景解读（谁 / 现状 / 痛点 / AI 角色）｜新确认事实｜数据依赖与待确认｜可计量性｜优先级。
输出沉淀到 `.context/customers/` 纪要，同步 todo。
陷阱：解读不能超出原话支持的范围；模糊处明确标"待确认"，不脑补。

### 阶段 2：场景地图

表格：场景 ×（客户热度 / 数据可得 / 可计量 / 组织阻力）→ 梯队（T0 试点 / T1 / T2 / T3）。
纪律：必须标注"这是初步判断，不是已证明的价值排名"。

### 阶段 3：需求纠偏（client-first lens）——必做，不可跳过

三个追问：
1. **谁是客户？** 可能不止一方（货主 / 司机 / 管理层 / 投资人），需求各不相同。
2. **客户买的到底是什么？** 是端到端承诺（安全准时交付 + 可信状态 + 无争议结算），不是岗位动作。
3. **指标是否错位？** 服务结果 = 主指标；内部效率 = 次级经济指标；合规安全 = 硬约束。

输出对照表：功能表述 → 应检验的真实需求 → 结果指标。
红线：工时 / FTE 下降不设为唯一北极星；未基线校准的百分比一律不承诺。

### 阶段 4：新增服务扫描

逐场景问：**过去因人力或协调成本做不了、现在 AI 能做的是什么？**
格式：过去限制 → 现在做法 → 新增价值 → 前提条件 → 边界。
红线：LLM 不替代优化计算、安全判断、法律判断；没有可信数据就不能提供可信状态。

### 阶段 5：N 角色思想实验（组织本质）

问："如果这家公司只留 N 个角色（通常 3），留谁？他们提供什么不可替代的服务？"
筛选标准：哪些职能失败时必须有具体的人负责——即**信用节点**（对客户的信任 / 对监管的担责 / 对运力或供应侧的关系）。
其余岗位全部重构为 Agent，产出岗位映射表：现岗位 → Agent 形态 → face 方向 → 人类留痕在哪（例外升级给谁）。
三个转变：Agent 的定义单位 = 一个客户的完整问题（不是岗位功能）；三角色 KPI 从流程管理 → 例外关闭；增长不带动办公室人头线性增长。

### 阶段 6：快赢选择与执行卡

入选条件：**一周内可落地（无 API / 数据工程依赖）+ ROI 一周内可观测 + client-facing 优先。**
产出：主推方案（D1-D7 执行卡：跟岗 → 搭建 → 灰度 → 复盘）+ 备选 + 决策判据（用可观测数据决定，如客服时间审计占比）。
纪律：一周只赌一个；赌赢的收益启动下一个；不并行。

### 阶段 7：交付序列

纪要（md）→ 综合方案（md）→ 内部讨论稿（HTML）→ 执行卡。
每轮讨论后版本递进（v1.0 → v1.1），文件头写明"变化了什么、哪些数字不承诺"；旧版保留为历史草稿。

## 汇报与讨论材料必备

- vN-1 → vN 变化说明（诚实呈现口径演进，含自我纠偏）
- 决策点清单（本次讨论要拿的确认，逐条可回答）
- 待挑战问题（主动列出内部应该质疑什么）
- 诚实边界（未验证事实 / 草稿数字 / 外部对标未核验）

## 常见陷阱

1. 把客户提及当批准——速记只能支持"存在需求方向"
2. 把内部效率当北极星——先问客户买的到底是什么
3. 把 LLM 当优化器——排车 / 价格 / 安全需要规则与求解器
4. 快赢并行——一周只赌一个
5. ROI 无归因边界——回款 / 中标受外部因素影响，先定归因规则
6. 数据请求一次全量——先样例与异常链路，按授权分批

## 验证需求理解的访谈工具

思想实验本身就是最好的访谈问题，直接问、不要再猜：
- 问客户："如果只留 N 个岗位你留哪三个？"——答案与模型的差异 = 需求理解的剩余差距
- 问客户：续约理由排序？出过什么事、谁处理的、满意吗？
- 问供应侧（司机/外协）：为什么跟你不跟别家？最想改哪件事？
- 问内部：现在谁在处理例外？一天几件、什么类型？——例外清单就是未来角色的 KPI 雏形
